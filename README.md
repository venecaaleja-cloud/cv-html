# Evaluación Git y GitHub

## Descripción
Esta evaluación tiene como objetivo demostrar el uso de Git y GitHub para el control de versiones, creación de ramas, realización de commits y unión de cambios mediante merge.

## Integrantes
- Diego Alejandro
- Jhon Correa

## Actividades realizadas
Durante el desarrollo de la evaluación se realizaron los siguientes procesos:

- Inicialización de un repositorio local con Git.
- Creación de la estructura base del archivo HTML.
- Creación de ramas para trabajar diferentes cambios.
- Realización de commits con los avances realizados.
- Actualización del perfil profesional.
- Creación de la sección de habilidades.
- Unión de ramas mediante el comando git merge.
- Subida de los cambios al repositorio remoto en GitHub.

## Historial de commits
Los cambios realizados se pueden evidenciar mediante el historial de Git, donde se muestran los commits realizados durante la evaluación.

## Conclusión
La evaluación permitió aplicar los comandos principales de Git y GitHub para gestionar cambios, trabajar con ramas y mantener un historial organizado del desarrollo realizado.
